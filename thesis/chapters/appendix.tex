\section{Reproduction Commands}
All commands were run on a Windows laptop with an RTX 3050 GPU, in PowerShell, from the project folder.
\begin{lstlisting}
python -m pytest -q                       # 29 tests
.\scripts\run_pipeline.ps1                # data, training, evaluation, benchmark
.\scripts\run_pipeline.ps1 -Seeds 3       # two extra training seeds + aggregate
python scripts/stateless_sweep.py --sets multihop,adaptive,realharm
.\scripts\run_pipeline.ps1 -Live          # live LLM agents (needs Ollama)
.\scripts\run_pipeline.ps1 -LLMBaselines  # LLM judge and NeMo

python -m uvicorn backend.main:app --port 8000   # API
cd frontend ; npm install ; npm start            # dashboard
\end{lstlisting}

\section{Result Files}
\texttt{results/benchmark.json} (seed 42, all systems), \texttt{results/seeds/summary.json} (mean and standard deviation over five seeds), \texttt{results/stateless\_sweep*.json} (matched false-positive comparison), \texttt{results/benchmark\_llamaguard.json}, \texttt{benchmark\_promptguard.json}, \texttt{benchmark\_protectai.json}, \texttt{benchmark\_llm.json} and \texttt{benchmark\_llm\_mapis.json} (153-session comparison), \texttt{results/live\_agentdojo.json} (live agents) \texttt{results/evaluate.json} (event-level metrics and latency), \texttt{results/calibration/} (calibrated cut-off), \texttt{results/stateattack/} (attacks on the session record), \texttt{results/ablation\_seed42.json} (rule ablation) and \texttt{results/benchmark\_independent.json} (team-written independent set).
