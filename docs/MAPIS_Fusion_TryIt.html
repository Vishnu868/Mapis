The calculation

The four tiers

TierTrustWhat happens
PASS0.75 or moreDelivered normally.
FLAG0.50 to 0.75Delivered, an alert is raised, session sensitivity +0.15 (maximum 0.6).
QUARANTINE0.25 to 0.50Held. The operator clicks Release or Reject in the console.
BLOCKbelow 0.25Dropped. The channel source → target is suspended for the rest of the session.

In the evaluation a session counts as detected when any of its messages is QUARANTINED or BLOCKED. If MAPIS itself fails, it fails closed (holds the message). The end user never sees MAPIS, only that an action was withheld.
